<h1 align="center">此刻 · Nowly</h1>
<p align="center">留意此刻，就够了。</p>
<p align="center"><a href="https://sandykidyao.github.io/nowly/">产品介绍</a> · <a href="https://github.com/SandyKidYao/nowly/releases/latest">下载 Android APK</a></p>

此刻是一款轻量的日常状态记录 App。在你设定的时间，停下来回答一个小问题，慢慢看见心情、压力或精力的变化。

- **按自己的方式记录**：自定义问题，选择回答选项或输入数字，设置每天或每周提醒。
- **回到生活**：选项轻点即保存，数字填写后确认保存；不方便时可以跳过。数字支持主动记录和过去日期补记。
- **看见日常规律**：回看状态的平均趋势、时段分布与记录色块，或持续跟踪体重等数字的变化。
- **数据由你掌握**：无需账号，离线使用；可导出 CSV、复制分析提示词，或通过完整项目文件备份和迁移。App 只在检查和下载新版本时联网，不上传任何数据。

支持 Android 8.0 及以上。安装后请允许通知；部分手机还需开启自启动和后台运行，见[提醒帮助](docs/background-reminders.md)。卸载或清除应用数据会丢失未备份的本地记录，请保留导出的完整项目文件。
