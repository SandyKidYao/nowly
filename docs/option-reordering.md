# 选项拖动排序 · 0.2.1

2026-09-18，versionCode 3。按用户确认的方案替换编辑页的“上移”文字按钮。

## 交互

- 左侧六点手柄，48dp 触控区域；中间输入框、右侧删除保持原位。
- 按住手柄直接拖动，行浮起并有位置动画；开始时收起键盘，避免与文字编辑争抢手势。
- 所有表单内容共用一个 LazyColumn，只有选项行可重排；手柄接近顶部或底部时自动滚动，保存按钮固定在页面底部。
- 无障碍手柄提供上移/下移动作，读出当前位置；边界处不提供无效方向，移到屏幕外时滚动跟随。
- 拖动只改变草稿顺序，保存后落库；返回放弃未保存调整。稳定选项 ID、已有记录与选项颜色保持对应。

## 实现

采用 [Reorderable 3.1.0](https://github.com/Calvin-LL/Reorderable/tree/v3.1.0)。按选项 ID 映射拖动来源和目标，不依赖表单全局行号计算选项顺序。原有数据库结构不变。

第三方 Apache-2.0 许可证及版权声明随 APK 保留在 `assets/licenses/`。
