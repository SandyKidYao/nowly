# 版本决策记录

按版本记录已确认的产品与实现决策。每轮的构建输出、测试日志、安装包校验值和真机截图属于过程材料，保存在 `tmp/`、`.local/`，不进版本控制。

## 0.2.5 · 2026-10-16 · 统计改为看平均变化，新增数据导出

- 选项一律视为有序等级：当前启用的选项按顺序为 1..N 级，已停用选项没有等级、不计入平均，但仍计入次数与占比。
- 统计页顶部改为概览：平均等级（如 3.6 / 5，接近「不错」）、与前一个同长度区间的平均差（↑/↓/持平，前期无回答时显示「无可比数据」）、等级色条上的平均位置标记，以及已回答 / 已跳过 / 未处理 / 回答率（回答率不含待处理）。
- 「日期趋势」改为「平均趋势」：折线为每天平均等级，日期轴连续（无回答的日期留空，前后有数据时以浅色虚线连接），虚线为整段平均；下方对齐的小色条为当天选项占比。点按图表显示当天日期、平均、最接近的选项与次数。超过 62 天的范围按周（周一开始）聚合。
- 时段分布每行增加该时段平均等级；占比条按等级从低到高排列。
- 图表色谱由单一苔绿明度阶改为按等级取色的发散色谱（赭石 → 暖灰 → 石板蓝），色值与校验见 [UI 品牌基线](nowly-ui-brand.md)。原调色板第一阶几乎与卡片底色相同，且颜色按选项创建顺序循环分配、超过 5 个选项会重复。
- 「记录」由逐条列表改为马赛克：一天一行（新日期在上），一个提醒时刻一列，每次提醒一格。已回答格按所选等级着色；已跳过与未处理在用户看来都是「未回答」，统一为实线空心框；待回答与没有提醒都是「暂无记录」，统一为小圆点。图例与选项颜色合为一行。格子不响应点按。行按记录日期归组，列按原定提醒时刻；范围内提醒时刻超过 12 个时按整点合并列。原列表删除，逐条明细可导出 CSV。
- 统计页最下方新增「导出数据」，沿用页面日期范围；标题右侧显示条数，不放说明文字。两行各配两个同宽按钮，「复制」固定在右列且为实心按钮，左列为该行特有操作（描边按钮）（CSV「保存」/ 提示词「预览」）：
  - CSV 表格：每条提醒一行（日期、时间、星期、状态、选项、等级、提醒时间、时区），含跳过 / 未处理 / 待处理；可复制，或通过系统文件选择器保存（UTF-8 带 BOM，表格软件可直接识别中文）。
  - AI 分析提示词：包含记录说明（问题、等级定义、提醒时间、状态含义）、概况、每日（或每周）平均、逐条记录和分析要求，可预览、一键复制。超过 1500 条时省略逐条记录。
- 数据库结构和版本不变，可覆盖升级。

## 0.2.4 · 2026-09-22 · 统计与记录合并，提醒开关移入设置

- 首页卡片只保留两个入口：点击项目名进入设置；右上角统计图标进入「统计」。移除卡片上的提醒开关和底部「设置 / 统计」文字入口。提醒关闭时名称下显示「已暂停」标记，无障碍描述同步追加。
- 设置页「采样提醒」右侧新增提醒开关，与名称、问题、选项、时间一起随「保存」提交；返回不保存则不改变开关。配置重建后开关值随草稿恢复。
- 「统计」页合并原历史页：名称与日期范围同行、日期靠右；上方为已回答 / 已跳过 / 未处理计数，接着是日期趋势、时段分布、按选项统计（常驻展开），下方为只含已填写记录的「记录」列表，按日期分组，每行为填写时间、选项色点、选项名。统计与记录共用同一个日期范围。
- 创建记录保存后直接进入该记录的统计页；独立历史页删除。
- 数据：`ProjectDraft` 新增可选 `remindersEnabled`，未提供时沿用现值；记录列表由统计的同一次日期范围查询派生，不再有独立的已回答分页查询。数据库结构和版本不变，可覆盖升级。
- 曾比较过三套卡片布局方案（顶部工具栏 / 右侧工具栏 / 底部文字入口），用户最终选择上述“两个入口”的结构，方案页存档于 `tmp/2026-09-22-card-layout-options.html`。

## 0.2.3 · 2026-09-22 · 文案去“项目”

- 界面中的“项目”字样统一去掉：创建记录、编辑、信息、名称、保存、删除、确认删除、统计。校验、加载和记录不存在的提示同步调整。
- 统计页日期范围移到与记录名称同一行并右对齐；保留点击日期范围打开筛选弹窗。

## 0.2.2 · 2026-09-22 · 按真机截图批注精简界面

- 首页卡片移除每天提醒次数与“手动时间点”说明。
- 历史只显示已填写记录；没有回答的日期不产生空分组。跳过、未处理和待处理记录不删除，仍计入统计，待处理仍可从首页回答。
- 统计页移除右上角“筛选”，点击日期范围打开原有弹窗。
- 创建与编辑页移除说明文字、普通分类 / 有序等级切换和提醒次数说明；删除改为与保存同尺寸的红色按钮，说明移入删除确认弹窗。
- 回答页移除底部固定说明；页头统一为矢量返回图标。
- 项目统一为有序等级：已有普通分类项目初始化时只把 `ordered` 置为 `true`，沿用既有选项顺序，ID、颜色、历史关联和提醒时间不变。

## 0.2.1 · 2026-09-18 · 选项拖动排序

- 编辑页选项行左侧为六点手柄（48dp 触控区），按住直接拖动，行浮起并有位置动画，开始拖动时收起键盘。所有表单内容共用一个 LazyColumn，只有选项行可重排；接近上下边缘自动滚动。
- 无障碍：手柄提供上移 / 下移动作并读出当前位置，边界处不提供无效方向。
- 拖动只改草稿顺序，保存后落库，返回放弃调整。稳定选项 ID、已有记录与选项颜色保持对应。
- 实现采用 [Reorderable 3.1.0](https://github.com/Calvin-LL/Reorderable/tree/v3.1.0)，按选项 ID 映射拖动来源与目标。Apache-2.0 许可证随 APK 保留在 `assets/licenses/`。
- 边缘滚动的设备测试使用 Android 真实帧时钟注入触控事件；Compose 虚拟时钟版本曾停滞，已替换。

## 0.2.0 · 2026-09-18 · MVP 首版

- 实现范围与边界见 [MVP 实现约定](mvp-implementation.md)。
- 验收基线：Debug APK、Lint（警告视为错误）、11 个 JVM 单元测试、22 个隔离模拟器设备场景；Release 构建通过 R8 但未配置正式签名。数据库 v2，提供从 v1 的保留数据迁移。
- 首版发现并修复：保存入口先建立预置项目；记录已提交后通知更新异常不误报为保存失败；普通回前台保留尚未完成的延迟提醒，重启 / 时间变化才重建；回答时间与时区在点选时确定；选项颜色单独保存；统一苔灰配色与圆角。
- 真机验收边界（模拟器不能替代）：锁屏与长时间休眠、省电与厂商后台限制、整机重启后的恢复、各系统版本与大字体、正式签名 release。其中 vivo 后台限制的排查结论见 [后台提醒真机排查](background-reminders.md)。
