# UI 与品牌规范

## 品牌与素材

名称：此刻 · Nowly。品牌短句：留意此刻，就够了。气质自然、安静、轻盈，文案短而具体，不给感受贴好坏标签。

标志为带留白的圆环与中央实心点；使用 [标志 SVG](../assets/brand/nowly-mark.svg) 和 [图标 SVG](../assets/brand/nowly-app-icon.svg)，不拉伸，不加钟表指针或情绪表情。Android 平台图标位于 `app/src/main/res/`。网页资产在 `site/assets/`，更新品牌时同步。

## 配色与尺度

固定苔灰浅色主题，不自动使用动态配色或深色主题。设计变量见 [JSON](nowly-design-tokens.json)，实际组件以 `ui/theme/Theme.kt` 为准。

| 角色 | 色值 |
| --- | --- |
| 页面背景 | `#F3F4EF` |
| 内容表面 | `#FCFCF9` |
| 主色 | `#526B5B` |
| 主按钮文字 | `#FFFFFF` |
| 正文 | `#29362F` |
| 辅助文字 | `#58665D` |
| 浅容器 | `#E5EAE1` |
| 边框 | `#D9E0D5` |
| 暖色点缀 | `#C6B7A1` |

正文/背景对比度约 11.42:1，辅助文字/背景约 5.47:1，白字/主按钮约 5.81:1。新增状态仍须检查对比度。

使用系统无衬线字体，适配系统字号，不依赖在线字体。首页标题 29sp，问题 27sp，卡片标题 17sp，正文 14sp，按钮 13sp，辅助 11sp，统计重点 28sp。卡片圆角约 17dp，控件 12dp，答案 14dp，面板 24dp。页面水平留白约 20dp，卡片内约 16dp；主要触控区至少 48dp，答案至少 52dp。卡片用细边框，避免重阴影。

## 图表

当前启用选项按等级取色：赭石 `#9A5B26` → 浅赭 `#D4AC80` → 暖灰 `#CDC8BC`（仅奇数级） → 浅蓝灰 `#9DB6C9` → 石板蓝 `#2E5E78`，两臂在 OKLab 插值；停用选项 `#8C8F88`。两端不代表好坏，压力与心情都可使用。

选项改名保留身份，调序则按新等级重新取色。色块加 1dp 淡描边，进度条用细线底槽。配合名称、次数、占比或图例，不只靠颜色识别。马赛克用颜色、空框、小点区分已回答、未回答、暂无记录。

## 页面与交互

- 首页卡片：名称进入编辑，右上角统计图标进入统计；暂停时显示标记，不在卡片上放开关。
- 回答页：大问题、等权重选项，选择即保存并返回来源。
- 编辑：一张滚动表单，选项左侧拖动手柄、右侧删除；提醒开关在提醒区，全部修改随保存提交。删除在表单底部，须确认。
- 统计：名称与日期同排，概览、趋势、时段、选项、马赛克和导出纵向展开，共用日期筛选。
- 不新增欢迎页、底部导航或账号入口。通知遵循 Android 系统容器。

页面行为与数据口径以[产品规则](product.md)为准；历次变更见[版本决策记录](changelog.md)。产品页截图来自模拟器演示数据，替换时不要使用个人状态记录。
