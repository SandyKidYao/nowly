# 产品规则

基线：0.2.6。此刻是 Android 本地日常状态采样工具，围绕自定义单问题、有序单选或数字记录、每日/每周提醒和回看统计展开。减少打扰，不要求补填错过的记录。

用语：被追踪的对象（如心情、体重）称「项目」，一次回答或测量称「记录」；「记录数字」「记录当下」是动作。界面和文档不混用。

## 项目与编辑

- 首次直接进入首页，一次性预置「心情」：问题「此刻，你的心情怎么样？」；选项「很不好、不太好、一般、不错、很好」；每天 10:00、12:00、15:00、17:00、20:00。删空后不重新预置。
- 首页点击项目卡片进入统计，编辑入口在统计页顶栏右侧；卡片内的「记录数字 / 记录当下」按钮直接进入填写，待处理提醒可进入回答。暂停的项目显示「已暂停」。没有独立历史页或底部导航。
- 名称 1–40 字，问题 1–160 字。选项项目有 2–20 个选项，每项 1–30 字。允许同名，身份以 ID 区分。选项按顺序视为从低到高的等级。
- 名称、问题、选项、提醒时间与开关在一张滚动表单内编辑，点击保存统一提交。返回放弃修改；配置变化和进程重建保留草稿。新建后进入统计，编辑保存或放弃后返回统计页。
- 选项用左侧手柄拖动排序，支持边缘自动滚动与无障碍上移/下移。排序只改草稿。
- 选项 ID 稳定。改名同步历史显示；移除实际为停用，保留历史引用。调整顺序会重新解释当前等级与图表颜色，历史不冻结旧等级。
- 暂停仅取消后续计划，保留当前待处理和通知。删除须确认，删除项目及全部记录并取消提醒，随后回到首页；取消确认保留草稿。

## 数字项目

- 新建时可选择「选项项目 / 数字项目」。数字项目设置一个固定单位（可空，最多 16 字）；「使用每周体重示例」填入体重、kg、每周日 08:00。提醒关闭时仍可主动记录。
- 有任何历史（含待处理提醒）后，项目类型和单位保持不变，避免重新解释历史。无历史时可切换类型；数字项目不创建回答选项。
- 首页及统计页提供「记录数字」。填写页显示问题、数值输入框、固定单位、最近一次记录与测量时间，必须点击保存；保存前不提交。
- 支持正数、负数和 0，最多 12 位整数、6 位小数；小数逗号可作为输入分隔符。使用十进制文本保存，去除多余的尾随 0，不经过二进制浮点数或静默四舍五入。不接受科学计数法、NaN、Infinity 或未填完的小数。
- 默认按保存时刻记录。可以选择过去的测量日期与时间，不接受未来时间；补记独立保存，不完成现有待处理提醒。「改为现在记录」恢复默认行为。
- 打开填写页时已有待处理提醒，正常填写会完成那一次提醒；旧提醒被替换后不能回答到新实例。没有待处理提醒时创建独立测量记录；填写期间新到的提醒保持待处理，并在页面说明。同一天可记录多次，重复提交不追加副本。
- 历史测量可修改数值、测量时间，或确认后删除。修改保留身份，不能用过期编辑覆盖已经改变的记录。错过、跳过、未处理与待处理提醒均不产生数值，不当作 0。

## 提醒与状态

支持每天或每周提醒；每周至少选择一天（周一至周日可多选），选中日期共用 1–24 个不重复时间点，精确到分钟；时间轴拖动按 15 分钟粗调。修改从下一未来时刻生效，不补发过去时间点。按当地日历日期与时刻重新计算，不使用固定 24 小时或 7×24 小时间隔。暂不支持随机或延后提醒；选项项目不支持回填。

| 当前状态 | 事件 | 结果 |
| --- | --- | --- |
| 待处理 | 选择答案，提交成功 | 已回答，保存选项 ID 与实际选择时刻 |
| 待处理 | 点击跳过、划掉、全部清除的回调 | 已跳过，不产生答案 |
| 待处理 | 同项目的新提醒替换 | 未处理，不产生答案 |
| 待处理 | 仅时间流逝、打开通知或不回答返回 | 保持待处理 |
| 已终结 | 重复或迟到事件 | 保持原结果，不重复写入 |

回答、跳过、替换通过统一串行入口和事务处理，先完成的有效操作获胜。旧回答页遇到新提醒须显示状态更新，不能把答案写到新实例。系统或程序自行移除通知不能推断用户跳过。

点击通知进入独立回答 Activity，选择即保存，提交成功才关闭并返回来源。时间和时区在点选时捕获。提交后的通知更新异常不能误报保存失败。

首次首页申请通知权限一次，拒绝后可从编辑页恢复。精确提醒需要独立系统授权；未获准则允许延迟。权限关闭时不虚构已发送实例。系统只调度下一次时刻，同刻多项目分别通知。

重启、系统时间/时区变化、授权恢复和回前台重新核对计划。普通回前台保留尚未完成的延迟提醒；重启等重建只安排未来。强制停止后需重新打开。厂商后台限制仍须真机验证，见[排查指南](background-reminders.md)。

## 日期、统计与导出

- 选项回答按实际填写时、数字回答按实际测量时的当地日期与小时归组；其他状态按计划日期。历史保存日期，切换时区不重分旧数据。
- 选项项目默认最近 7 天，数字项目默认最近 30 天，均可选 7/30 天或自定义含首尾日期。统计、记录马赛克与导出共用范围；仅看当前项目。
- 启用选项按当前顺序为 1..N 级；停用选项计入次数和占比，但不计平均。等级平均用于观察变化，不是经过校准的测量分值。
- 概览包括平均等级、最近选项、与前一个同长度区间的差、已回答/已跳过/未处理数量和回答率。回答率 = 已回答 ÷（已回答 + 已跳过 + 未处理），不含待处理。无数据保持空值，不当成 0。
- 趋势按日平均，超过 62 天按周（周一开始）聚合。保留连续日期，无回答留空；整段平均虚线、下方占比色条及点按详情辅助阅读。
- 时段边界为 00–08、08–12、12–16、16–20、20–24；选项分布以已回答为分母，按稳定 ID 聚合。
- 马赛克一天一行，新日期在上；列为原定提醒时刻。已回答按等级着色，跳过/未处理为空框，待处理/无提醒为小点。超过 12 个提醒时刻按整点合并；同格显示较晚事件。格子不响应点按。
- CSV 每条提醒一行，包含日期、时间、星期、状态、选项、等级、提醒时间、时区，按事件时间正序。支持复制和系统文件选择器保存，保存为 UTF-8 BOM。
- 分析提示词包含问题、等级、提醒时间、状态定义、汇总、趋势和明细；超过 1500 条省略逐条数据。支持预览、复制，由用户自行粘贴到外部 AI 工具，App 不上传数据。

### 数字项目的统计与导出

- 显示所选范围内最近一次测量、日期及时间、较上一次的精确差值和两次测量的实际间隔。只有一次时不虚构变化。
- 趋势图按保存的测量日期/当地时间布点，连接真实测量点，不为缺测日补值。使用中性颜色，上升和下降不自动代表好坏。
- 测量明细按实际时间倒序，每条显示数值、单位、日期和时间，可进入修改。该列表不把未回答的提醒呈现为测量。
- CSV 使用同一日期范围，列为日期、时间、星期、状态、数值、单位、提醒时间、时区、来源；包含无数值的提醒状态，主动记录没有提醒时间。AI 提示词提供原始数值与变化，不包含等级量表、健康诊断或目标建议。

## 项目备份与迁移

- 首页「导入项目」读取 `.nowly` 文件；统计页「导出数据 → 完整项目 → 导出项目」保存完整项目。原 CSV 和 AI 提示词导出保持原有范围与行为。
- 完整项目文件包含名称、问题、稳定 ID、选项顺序/颜色/停用状态、提醒时间/开关和全部历史，不受统计日期筛选影响。历史保存日期、时区与状态原样保留。
- 导入先校验文件格式版本、大小（最多 32 MB）、字段、身份引用和状态，再预览项目名称、启用选项数、历史数量及导出时间。文件是 UTF-8 JSON，格式版本独立于数据库版本；当前写入 v2（含项目类型、单位、星期规则、数字与主动记录来源），兼容读取原 v1 选项项目。
- 无同 ID 项目时新增；存在同 ID 项目时明确显示目标项目名称及历史数量，用户确认后整体替换该项目，不合并历史。同名不同 ID 可共存，其他项目不受影响。
- 导入在单一数据库事务中提交，并与回答/跳过/提醒触发共用串行入口。冲突、损坏文件和写入失败不会留下部分导入；取消不改数据。重复确认恢复同一文件不会追加重复历史。
- 提交后清理该项目旧通知，静默恢复待处理通知，仅安排未来提醒，不补发过去时间。系统通知/准时提醒权限由目标 App 单独授权；权限未开启时给出提示。两个 App 的提醒独立，迁移后由用户关闭旧 App 提醒。
- 完整项目文件不包含系统权限、闹钟令牌或其他项目。导出不会暂停或修改来源项目。覆盖无法撤销，需保留旧数据时先导出目标项目。

## 应用更新

- 仅正式版（包名 `com.nowly.app`）提供。Debug 版包名和签名不同，无法被正式 APK 覆盖，只在首页底部显示版本号。
- 版本信息来自产品页的 `release.json`，只在正式发布时更新，预发布不推送给用户。App 只接受 HTTPS 上本仓库 Release 资产的下载地址，其他地址视为无效。
- 回到前台时自动检查：成功后 24 小时内不再检查，失败 1 小时后才重试。没有新版或检查失败时不打扰。「自动检查更新」默认开启，可在「版本与更新」弹窗关闭，关闭后 App 不主动联网；手动「检查更新」随时可用，结果在弹窗内显示。
- 发现 versionCode 更高的正式版后，首页顶部显示提示条。「忽略此版本」只隐藏这一版的提示条，仍可从首页底部的版本入口查看和安装；之后出现更高版本时重新提示。
- 「下载并安装」在应用内下载到缓存目录，显示进度，可取消。下载后校验大小与 SHA-256，并确认安装包是本应用且版本号与公告一致；不符即删除并提示。通过后调起系统安装器，由用户确认；首次需在系统中允许此应用安装未知应用，签名不同的安装包由系统拒绝。
- 覆盖安装保留全部数据。已安装或过期的安装包在下次启动时清理。下载失败或无法打开安装器时可打开下载页手动安装。
- 检查和下载只发出读取请求，不附带用户数据、设备标识或使用统计。

## 数据边界

无需账号、后端或云同步。网络只用于检查和下载新版本，不上传任何数据；其余功能离线可用。数据库为 v3，保留 v1→v2→v3 的非破坏性迁移；不得采用清空旧库的破坏性迁移。关闭系统备份并配置备份/迁移排除规则，厂商设备迁移行为仍需实机核验。

支持通过完整项目文件导入恢复，不支持将分析用 CSV 导入为完整项目。未保留项目文件时，卸载、清除数据或丢失手机可能永久丢失记录。iOS、多题问卷、文本/数值输入、健康设备、同步与自动分析均未纳入当前范围。
