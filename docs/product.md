# 产品规则

基线：0.2.5。此刻是 Android 本地日常状态采样工具，围绕自定义单问题、有序单选、每日提醒和回看统计展开。减少打扰，不要求补填错过的记录。

## 记录与编辑

- 首次直接进入首页，一次性预置「心情」：问题「此刻，你的心情怎么样？」；选项「很不好、不太好、一般、不错、很好」；每天 10:00、12:00、15:00、17:00、20:00。删空后不重新预置。
- 首页点击名称进入编辑，右上角图标进入统计；待处理提醒可进入回答。暂停的记录显示「已暂停」。没有独立历史页或底部导航。
- 名称 1–40 字，问题 1–160 字，2–20 个选项，每项 1–30 字。允许同名，身份以 ID 区分。所有选项按顺序视为从低到高的等级。
- 名称、问题、选项、提醒时间与开关在一张滚动表单内编辑，点击保存统一提交。返回放弃修改；配置变化和进程重建保留草稿。新建后进入统计，编辑后返回首页。
- 选项用左侧手柄拖动排序，支持边缘自动滚动与无障碍上移/下移。排序只改草稿。
- 选项 ID 稳定。改名同步历史显示；移除实际为停用，保留历史引用。调整顺序会重新解释当前等级与图表颜色，历史不冻结旧等级。
- 暂停仅取消后续计划，保留当前待处理和通知。删除须确认，删除记录及全部历史并取消提醒；取消确认保留草稿。

## 提醒与状态

每日 1–24 个不重复时间点，精确到分钟；时间轴拖动按 15 分钟粗调。修改从下一未来时刻生效，不补发过去时间点。每天按当地时刻重新计算，不使用固定 24 小时间隔。暂不支持星期、随机、延后或回填。

| 当前状态 | 事件 | 结果 |
| --- | --- | --- |
| 待处理 | 选择答案，提交成功 | 已回答，保存选项 ID 与实际选择时刻 |
| 待处理 | 点击跳过、划掉、全部清除的回调 | 已跳过，不产生答案 |
| 待处理 | 同记录的新提醒替换 | 未处理，不产生答案 |
| 待处理 | 仅时间流逝、打开通知或不回答返回 | 保持待处理 |
| 已终结 | 重复或迟到事件 | 保持原结果，不重复写入 |

回答、跳过、替换通过统一串行入口和事务处理，先完成的有效操作获胜。旧回答页遇到新提醒须显示状态更新，不能把答案写到新实例。系统或程序自行移除通知不能推断用户跳过。

点击通知进入独立回答 Activity，选择即保存，提交成功才关闭并返回来源。时间和时区在点选时捕获。提交后的通知更新异常不能误报保存失败。

首次首页申请通知权限一次，拒绝后可从编辑页恢复。精确提醒需要独立系统授权；未获准则允许延迟。权限关闭时不虚构已发送实例。系统只调度下一次时刻，同刻多记录分别通知。

重启、系统时间/时区变化、授权恢复和回前台重新核对计划。普通回前台保留尚未完成的延迟提醒；重启等重建只安排未来。强制停止后需重新打开。厂商后台限制仍须真机验证，见[排查指南](background-reminders.md)。

## 日期、统计与导出

- 已回答按实际填写时的当地日期与小时归组；其他状态按计划日期。历史保存日期，切换时区不重分旧数据。
- 默认最近 7 天，可选 30 天或自定义含首尾日期。统计、记录马赛克与导出共用范围；仅看当前记录。
- 启用选项按当前顺序为 1..N 级；停用选项计入次数和占比，但不计平均。等级平均用于观察变化，不是经过校准的测量分值。
- 概览包括平均等级、最近选项、与前一个同长度区间的差、已回答/已跳过/未处理数量和回答率。回答率 = 已回答 ÷（已回答 + 已跳过 + 未处理），不含待处理。无数据保持空值，不当成 0。
- 趋势按日平均，超过 62 天按周（周一开始）聚合。保留连续日期，无回答留空；整段平均虚线、下方占比色条及点按详情辅助阅读。
- 时段边界为 00–08、08–12、12–16、16–20、20–24；选项分布以已回答为分母，按稳定 ID 聚合。
- 马赛克一天一行，新日期在上；列为原定提醒时刻。已回答按等级着色，跳过/未处理为空框，待处理/无提醒为小点。超过 12 个提醒时刻按整点合并；同格显示较晚事件。格子不响应点按。
- CSV 每条提醒一行，包含日期、时间、星期、状态、选项、等级、提醒时间、时区，按事件时间正序。支持复制和系统文件选择器保存，保存为 UTF-8 BOM。
- 分析提示词包含问题、等级、提醒时间、状态定义、汇总、趋势和明细；超过 1500 条省略逐条数据。支持预览、复制，由用户自行粘贴到外部 AI 工具，App 不上传数据。

## 数据边界

无需账号、网络权限、后端或云同步。数据库为 v2，保留 v1 迁移；不得采用清空旧库的破坏性迁移。关闭系统备份并配置备份/迁移排除规则，厂商设备迁移行为仍需实机核验。

当前支持导出，不支持导入恢复。卸载、清除数据或丢失手机可能永久丢失记录。iOS、多题问卷、文本/数值输入、健康设备、同步与自动分析均未纳入当前范围。
