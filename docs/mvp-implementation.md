# Nowly MVP 实现约定

2026-09-18。基于需求 v8、线框 v0.8、苔灰视觉和已确认技术栈。以下补足原需求的待定边界，是本次实现选择，后续可以调整；不把它们倒写成原先已确认的需求。

- 首次预置心情：问题「此刻，你的心情怎么样？」；选项「很不好、不太好、一般、不错、很好」；每天 10:00、12:00、15:00、17:00、20:00。只初始化一次，删空后保持空状态。
- 项目名 1–40 字，问题 1–160 字；2–20 个选项，每项 1–30 字。同名允许，ID 各自独立；删除选项实际为停用。顺序使用左侧手柄拖动调整，也提供无障碍“上移/下移”操作；调整只改草稿，随“保存项目”统一落库。分类与等级均展示分布，不计算平均分。
- 每日 1–24 个不同时间点，精确编辑到分钟，拖动按 15 分钟粗调；同日中途修改从下一未来时刻生效，不补发过去提醒。不增加星期或随机模式。
- 暂停保留当前待处理实例和通知，只取消后续计划。删除通过确认面板一并删除项目及记录，并取消相关提醒。
- 新提醒替换原待处理实例为未处理；回答、跳过、替换由同一串行入口和数据库事务处理，先完成的有效操作获胜。重复事件不重复终结。旧回答页收到新提醒后须提示状态更新，不能悄悄将选择写入另一条提醒。
- 点击通知不会自动移除通知；未作答返回仍待处理。明确跳过/划掉/清除才记已跳过。系统自行移除不推断用户跳过。没有自动过期。
- 回答时间在点击选项时捕获，提交成功才返回来源。历史先按保存的当地日期倒序分组，同日按回答时刻（未回答按计划时刻）倒序，每批加载 30 条；日期按该事件发生时的当地日期记录，切换时区不重分历史。
- 统计默认最近 7 天，可选 30 天或自定义含首尾的日期；时段为 00–08、08–12、12–16、16–20、20–24。跳过/未处理按计划日期统计数量，答案仅按填写日期/小时分组。
- 首次首页申请通知权限一次；拒绝后可从编辑页恢复。精确权限是单独的系统设置入口。未授权时采用可能延迟的提醒，并在既有页面说明；此降级方式已由用户于 2026-09-18 明确确认。
- 系统统一调度下一次时刻，同刻多项目分别发通知。权限关闭时不虚构已发送的采样；重启、时间/时区改变、授权恢复、App 回前台重建未来计划。普通回前台保留系统已有但尚未完成的延迟提醒，避免把它误取消；重启等重建时只安排未来时刻，错过的时间点不批量补发。强制停止后需重开应用。
- 新建或编辑保存后到该项目详情；返回未保存的表单放弃草稿，配置变化/进程重建期间使用保存状态保留草稿。取消删除确认保留草稿。
- 本版本机存储，无账号、导出、云同步或网络权限。升级从初始化数据库 v1 保留数据迁移。正式生产签名与真机厂商适配属于分发验收。

验证覆盖：状态竞争与幂等、稳定选项改名/停用、填写时间统计、预置幂等、迁移、应用创建编辑与返回、系统通知动作及调度恢复。模拟器验证与实际手机连续使用验证分开记录。
