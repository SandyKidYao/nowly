05 / OPEN DECISIONS

线框已经具体，规则仍可讨论。

记录通过稳定选项 ID 关联标签，改名无需拆分历史。页面围绕项目组织；默认值、删除和问题变更等细节仍为拟议。

01 / 记录入口先点击通知，再单选即保存

已确认：通知正文进入回答，点选即按填写时间保存并直接返回。无单独成功页或失败页。误触修正与未作答返回仍待规格确认。

查看 C02 →
02 / 项目与历史标签改名同步历史，记录时间不变

记录引用稳定选项 ID，显示当前名称；改名不改变 ID、时间或统计次数，不按文字重新分组。新增选项分配新 ID，移出的选项保留历史引用。编辑无需修改影响确认页。

查看 D01 编辑页 →
03 / 统计日期、时段、选项，同页查看

统计锁定当前项目，只筛选日期。日期与时段按填写时间分组，选项显示次数与占比；跳过、未处理不进入答案分布。统计页不再链接独立记录页面。

查看 E01 合并统计 →
04 / 提醒规则新提醒替换旧提醒，不设置超时期限

已确认：每项目保留最新待处理通知，旧的被替换后标为未处理；点跳过、划掉记已跳过。提醒改为手动时间点；最少/最多时间点、重复时刻、当天修改与已打开回答页时收到新提醒等边界待定。
